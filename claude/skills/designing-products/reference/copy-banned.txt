# check-copy.mjs reads this: `phrase | reason`, one per line. Case does not matter; a space or hyphen
# matches either; a trailing * matches any ending (unlock* finds unlocks, unlocking). A product appends
# its own lines to its copy. A real use (a vault that unlocks) takes `copy-ok: <reason>` on its line.

seamless* | hype; name the step that disappeared

game changer | hype; say what changed, with a number and its source

in today's fast paced | filler opener; start with the product

unleash* | metaphor; say what the user can now do

next generation | hype; name what is new
