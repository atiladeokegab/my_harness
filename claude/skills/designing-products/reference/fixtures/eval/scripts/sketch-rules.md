# Round 1 sketch rules (tournament.md §1 "Sketch")

- One HTML file per line: `<dir>/<n>.html` where n is the line number.
- One screen: the content sheet's Screen 1 only, its words verbatim (heading, numbers, button text, freshness, footer).
- About 70 lines of HTML. System fonts only. Flat colours. Inline SVG for the line's memorable thing.
  No images, no JS, no web fonts, no external requests.
- Rough on purpose: the judge cuts directions, not finish. Make the line's mechanism and memorable thing
  unmistakable at 1280x633, and lay it out as a phone screen at 390x757 too (a media query).
- Follow the line as written: its layout idea, palette, type. Do not drift towards the other lines.
- Do not open other sketchers' files. Do not render or screenshot; the parent does that.
