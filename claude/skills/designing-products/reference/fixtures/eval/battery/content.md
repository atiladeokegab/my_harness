Written once by the parent from `brief.md`; every sketcher, builder and polisher uses it verbatim. All
numbers are illustrative.

**One name per thing.** The store is *the battery* (never "BESS" or "asset"). Sending charge to the grid
is *discharge*. A half-hour is a *period*. The price is *price*, in pence per kWh. The village's use is
*demand*. The person is *you*. Sentence case everywhere.
